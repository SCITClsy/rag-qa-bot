# 📚 公司知识库问答助手（RAG 实战项目）

> 一个可直接运行的 **RAG（检索增强生成）** 私有文档问答机器人。
> 上传 PDF/Word/TXT 文档 → 自动建知识库 → 基于资料回答问题，**附引用来源、杜绝编造**。
> 全程本地运行（Ollama + Chroma），**零 API 成本**。

---

## 🎯 项目背景与解决痛点

公司内部员工查询制度、SOP、产品文档时，往往要翻几百页资料、效率低且易遗漏。
本项目把文档沉淀为**可对话的知识库**，员工像聊天一样直接提问，秒出带引用的答案。

---

## 🛠️ 技术栈

| 模块 | 技术 |
|---|---|
| 语言 | Python |
| 对话模型 | Ollama + llama3.1:8b（本地，免费） |
| 嵌入模型 | Ollama + nomic-embed-text（本地，免费） |
| 向量库 | Chroma（本地持久化） |
| 框架 | LangChain |
| 界面 | Streamlit（网页可视化） |
| 文档解析 | PyPDFLoader / Docx2txtLoader |

## 📁 项目结构

```
rag-qa-bot/
├── config.py          # 统一配置（模型名、切分参数、安全词，改这里即可）
├── ingest.py          # 文档入库：加载→切分→向量化→存向量库
├── app.py             # Streamlit 问答界面（上传、建库、提问、显示引用）
├── prompts.py         # 提示词模板（控制幻觉 + 防注入，面试重点）
├── requirements.txt   # 依赖清单
└── docs/              # 示例文档（可直接入库测试）
    └── 考勤制度示例.txt
```

## 🚀 快速开始（4 步）

### 第 0 步：安装 Ollama（本地大模型，免费）

```bash
# 1. 去 https://ollama.com 下载安装 Ollama
# 2. 拉取对话模型和嵌入模型
ollama pull llama3.1:8b
ollama pull nomic-embed-text
# 3. 启动服务（保持终端开着）
ollama serve
```

### 第 1 步：安装 Python 依赖

```bash
pip install -r requirements.txt
```

> 建议用虚拟环境：`python -m venv venv` 然后激活后再装。

### 第 2 步：文档入库（建知识库）

```bash
# 方式一：命令行批量入库
python ingest.py docs/

# 方式二：网页上传（启动界面后左侧上传，更方便，见第3步）
```

### 第 3 步：启动问答界面

```bash
streamlit run app.py
```

浏览器自动打开 http://localhost:8501，输入问题即可：

> 💬 提问示例：
> - "请假的流程是什么？"
> - "迟到怎么扣钱？"
> - "年假有几天？"

## 🧠 核心流程

```
上传文档 ──> 文本切分(重叠) ──> 向量化 ──> 存入 Chroma
                                            │
用户提问 ──> 安全校验 ──> 检索 Top3 片段 ──> 组装提示词 ──> 大模型生成 ──> 带引用回答
```

## ✨ 难点与优化（README 必写，面试就讲这些）

1. **控制幻觉（最重要）**
   - 系统提示词强制"只能基于检索资料回答，不知道就说不知道"
   - 返回答案附带引用来源，方便核对
2. **文本切分调优**
   - 用 `chunk_size=800, chunk_overlap=120`，优先按句子切（。！？），避免一句话被切开
   - 踩坑记录：chunk 太大→幻觉变多；太小→上下文断裂，反复调参后取折中
3. **Prompt 注入防护（结合测试背景）**
   - 输入层：敏感词过滤 + 指令注入特征识别
   - 输出层：系统提示词要求拒绝执行与知识库无关的指令
4. **低温度保稳定**：`temperature=0.1`，减少随机性，答案更可靠

## ⚠️ 常见问题排查

| 问题 | 解决 |
|---|---|
| 提示连接 Ollama 失败 | 确认 `ollama serve` 已启动 |
| 拉模型慢 | 换镜像或耐心等待，只需一次 |
| 入库后没变化 | 重启 app.py，或检查是否重建成功 |
| 中文乱码 | 确认 txt 文件为 UTF-8 编码 |
